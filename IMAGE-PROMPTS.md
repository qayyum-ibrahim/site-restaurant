# Image prompts: Saffron & Smoke (restaurant)

For you, not for Claude Code. Paste these into ChatGPT, one image per prompt.

## How to use
1. Start ONE new ChatGPT chat for this site. Paste the "Style" block first and say: "Remember this style for every image I ask for in this chat."
2. Then paste the prompts below one by one. Keep the same chat so the look stays the same.
3. Download each image and save it as **JPG** with the exact file name shown. Put the files in `site-restaurant/public/images/`.
4. Keep each file under about 400 KB so the site loads fast. Resize or compress them if they are bigger.
5. If a result has text, a logo or a strange hand, ask ChatGPT to try again. Add: "no text, no logo, no watermark."
6. Sizes: ask for landscape, portrait or square as shown. Exact pixel sizes can differ. The site crops images to fit, so a small difference is fine.
